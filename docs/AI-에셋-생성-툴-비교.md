# AI 에셋 생성 툴 비교 — 3D 모델 · 2D 아트 · 사운드

> 이 게임처럼 **에셋을 직접 만들 여력이 없는 1인/소규모 프로젝트**가
> 캐릭터·소품·배경음·효과음을 AI로 조달할 때 어떤 도구를 쓰면 되는지 정리한 문서입니다.
>
> 조사 기준일: **2026년 8월**. 가격·정책은 이 바닥에서 3개월이면 바뀌니 결제 전 공식 페이지 재확인 필수.

현재 이 프로젝트 상태:
- 3D 모델 5종 (`assets/models/*.opt.glb`) — 외부에서 받아온 것
- 텍스처 — `src/world.js`에서 Canvas로 직접 그림 (파일 0개)
- 사운드 — `src/audio.js`에서 WebAudio로 합성 (파일 0개, [사운드-합성-정리.md](./사운드-합성-정리.md) 참고)

즉 **모델만 외부 의존**인 구조라, 아래 표에서 3D 파트가 제일 실전에 가깝습니다.

## 1. 3D 모델 생성 — 이 프로젝트에 제일 중요한 파트

### 1-1. Meshy — "고민되면 일단 여기"

| 항목 | 내용 |
|---|---|
| 인지도 | **최상위**. AI 3D 생성기 비교글에 100% 등장하는 기준점 |
| 강점 | UI 완성도, Blender/Unity/Unreal **공식 플러그인**, text→3D와 image→3D 둘 다 성숙 |
| 약점 | 생성 속도가 느린 편 (모델당 5~8분대), 토폴로지는 Tripo보다 지저분하다는 평 |
| 무료 | 월 100 크레딧. **출력물이 CC BY 4.0** → 출처만 표기하면 상업 이용 가능 |
| 유료 | Pro $20 (1,000cr) / Premium $40 (3,000cr) / Ultra $100 (8,000cr) / Studio $70 (공유 5,500cr) |

**무료 티어가 CC BY 4.0**이라는 게 큰 차별점입니다. 크레딧 표기만 하면 무료로 뽑은 모델을 상업 프로젝트에 넣을 수 있어요. 경쟁사 대부분은 무료 티어 상업 이용을 막습니다.

### 1-2. Tripo AI — 게임 에셋 관점에서는 여기가 더 낫다

| 항목 | 내용 |
|---|---|
| 인지도 | **최상위**. 2026년 비교글에서 "먼저 써볼 툴"로 자주 1순위 지목 |
| 강점 | **속도**(Smart Mesh 로우폴리 약 2초), 쿼드 기반 깔끔한 토폴로지, 4K PBR 텍스처, 오토 리깅 + 애니메이션 포함 |
| 약점 | **무료 티어는 상업 이용 금지**. 상업 프로젝트면 결제 필수 |
| 가격 | $19.90/월부터. API도 별도 제공 |

이 프로젝트처럼 **웹에서 GLB를 로드하는 구조**라면 폴리곤 수가 곧 로딩 시간이므로, 쿼드 로우폴리를 바로 뽑아주는 Tripo가 후처리 부담이 가장 적습니다. `tools/optimize-glb.mjs`로 한 번 더 조여야 하는 건 어느 쪽이든 동일하고요.

### 1-3. Rodin (Hyper3D) — 품질 우선

- 포토리얼 오브젝트, 정밀한 UV·PBR·토폴로지에 강함. "프로덕션 납품 가능"을 내세우는 포지션.
- 대신 **생성에 15분 안팎**. 반복 실험용은 아니고, 최종 히어로 에셋 뽑을 때 쓰는 도구.
- 캐릭터보다 하드서피스·소품 쪽에서 평가가 좋습니다.

### 1-4. VARCO 3D (NC AI) — 국산, 파이프라인 전체를 커버

| 항목 | 내용 |
|---|---|
| 출시 | **2025년 12월 1일**. 국내 게임사가 3D 생성 AI를 상용화한 첫 사례 |
| 범위 | 메시 생성 → **PBR 텍스처 → 리깅 → 모션 리타게팅**까지 자동. 여기가 진짜 차별점 |
| 편집 | 특정 메시 영역 유지한 채 오브젝트 추가/삭제, **폴리곤 수·토폴로지 직접 조절** |
| 무료 | 2,000 크레딧 ≈ 3D 에셋 10개 |
| 유료 | 플러스 ₩22,000/월 (10,000cr) / 프리미엄 ₩165,000/월 (75,000cr) — **에셋당 약 500원** |
| 인지도 | 해외에선 거의 무명. **국내 게임업계 한정으로는 인지도가 꽤 높음** (출시 당시 언론 대거 보도) |

엔씨소프트에서 분사한 NC AI가 만들었고, **리깅 + 모션 리타게팅까지 자동으로 해주는 게 경쟁사 대비 확실한 우위**입니다. 해외 툴은 대부분 "메시 + 텍스처"까지만 주고 리깅은 따로 붙여야 하거든요. 이 게임의 `src/models.js`가 `SkeletonUtils`로 스킨드 메시를 다루고 있으니, 새 적 캐릭터를 추가한다면 실제로 손이 제일 덜 갈 선택지입니다.

같은 회사에서 **VARCO 사운드**(2026년 1월 출시)도 내놨습니다. 3D와 사운드를 한 계정에서 처리할 수 있다는 게 국내 팀 입장에선 편의성이 큽니다.

### 1-5. Hunyuan3D (텐센트) — 돈 대신 GPU를 내는 선택

- **모델 가중치와 학습 코드까지 공개된 오픈소스** (2.x 계열). 라이선스 조건만 지키면 로컬에서 무제한 생성.
- image→3D + PBR 머티리얼까지 나옵니다. 구독료 0원.
- 대신 **VRAM 넉넉한 GPU와 파이썬 환경 세팅이 필요**하고, 웹 서비스들의 편의 기능(리깅, 리메시, 원클릭 익스포트)은 직접 붙여야 합니다.
- 인지도는 "일반 사용자에겐 낮고, AI/그래픽스 개발자 사이에선 매우 높은" 전형적인 오픈소스 패턴.

### 1-6. 그 외

## 2. 2D 아트 / 텍스처

이 게임은 텍스처를 `world.js`에서 코드로 그리고 있어서 당장은 급하지 않지만, UI 아이콘·스킬 아이콘·타이틀 아트가 필요해지면 이쪽입니다.

| 툴 | 인지도 | 특징 |
|---|---|---|
| **Scenario** | ★★★☆☆ | **내 아트 스타일로 커스텀 모델을 학습**시켜 일관된 에셋을 대량 생산. $15/월에 상업 권리 포함. 1인~소규모에 가성비 최고 |
| **Layer.ai** | ★★☆☆☆ | 같은 목적이지만 **대형 모바일 팀**용. 시트 단위·대량 생산 최적화 |
| **범용 이미지 생성기** | ★★★★★ | Midjourney·DALL·E·Stable Diffusion 계열. 접근성은 최고지만 **스타일 일관성 유지가 어려움** — 아이콘 20개를 같은 톤으로 뽑는 게 고통 |

게임 에셋에서 진짜 어려운 건 "예쁜 그림 한 장"이 아니라 **"같은 톤의 그림 50장"**입니다. 그래서 범용 생성기보다 스타일 학습이 되는 Scenario 같은 게 실무에서 이깁니다.

## 3. 음악 · 사운드

### 3-1. Suno / Udio — BGM

| 항목 | Suno | Udio |
|---|---|---|
| 인지도 | **★★★★★ — AI 음악 = Suno** 소리 들을 정도 | ★★★★☆ — 명확한 2인자 |
| 라이선스 | **유료 플랜에서만 상업 이용 허용** | 동일 |
| 최근 변화 | Warner Music과 라이선스 협약 → 2026년 정책 개편 | **UMG와 소송 합의(2025-10-29)** 후 라이선스 기반 플랫폼으로 전환 |

**꼭 알아야 할 3가지:**

1. **2026년부터 무료 플랜 결과물은 개인·비상업 용도로 제한**됩니다. 게임에 넣으려면 유료 플랜이 필요해요.
2. 유료 플랜이 주는 건 **"상업적 사용 라이선스"이지 저작권 소유권이 아닙니다.** 미국 저작권청은 사람의 창작적 개입 없이 AI가 만든 결과물은 저작권 등록 대상이 아니라는 입장이라, 남이 똑같은 트랙을 써도 막을 수단이 없습니다.
3. 익스포트한 파일에 **Content Credentials 메타데이터**가 박힙니다. 어떤 AI 모델이 만들었는지 플랫폼이 식별할 수 있어요. 스팀·스토어 심사나 유통 시 "AI 생성물 고지" 항목과 직결됩니다.

### 3-2. ElevenLabs Sound Effects — 효과음

| 항목 | 내용 |
|---|---|
| 인지도 | **최상위**. 음성 합성으로 이미 유명해서 브랜드 신뢰도가 높음 |
| 방식 | 텍스트 프롬프트 → 효과음. v2 기준 길이 0.5~22초 지정, **loop 파라미터 지원** |
| 무료 | 월 50개 |
| 유료 | 생성당 200 크레딧. Starter 플랜 이상에서 사용 가능. **유료 플랜 출력물은 로열티 프리 상업 이용 가능** |
| 신기능 | **Video-to-Sound** (2026년 3월) — 영상을 넣으면 장면에 맞는 효과음을 자동 생성 |

loop 파라미터가 있다는 건 게임 입장에서 꽤 큽니다. 앰비언트(바람 소리, 던전 웅웅거림)를 이음매 없이 반복시킬 수 있으니까요.

### 3-3. VARCO 사운드 (NC AI)

2026년 1월 출시. VARCO 3D와 같은 계정·크레딧 체계로 묶여 있어서, **3D와 사운드를 한 곳에서 처리**하고 싶은 국내 팀에게 의미가 있습니다. 다만 ElevenLabs 대비 레퍼런스가 아직 적습니다.

## 5. 실제로 쓰기 전 체크리스트

1. **무료 티어의 상업 이용 조건을 반드시 확인.** Meshy는 되고(표기 조건), Tripo는 안 됩니다. 여기서 갈리는 프로젝트가 많습니다.
2. **AI 생성물 고지 의무.** Steam은 AI 생성 콘텐츠 사용 여부를 등록 시 신고하게 합니다. 3D·음악·이미지 전부 해당됩니다.
3. **저작권 등록은 안 됩니다.** AI 단독 생성물은 보호받지 못하니, 핵심 아이덴티티(로고·메인 캐릭터)는 사람 손을 거치는 게 안전합니다.
4. **폴리곤 수 확인 필수.** AI 생성 모델은 기본적으로 무겁습니다. 이 프로젝트도 `tools/optimize-glb.mjs`로 한 번 조여서 `.opt.glb`를 만들고 있죠. 용어가 헷갈리면 [3D-최적화-용어집.md](./3D-최적화-용어집.md) 참고.
5. **리깅 여부.** 대부분의 툴은 메시+텍스처까지만 줍니다. 움직여야 하는 캐릭터라면 리깅이 포함된 툴(VARCO 3D, Tripo)을 고르거나 Mixamo 같은 걸 따로 태워야 합니다.
